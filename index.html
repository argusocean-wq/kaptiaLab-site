PERSONAL ASSISTANT

讓助手逐步理解你，而不是每次從零開始

01 / MEMORY

本機長期記憶

每台電腦保留自己的近期對話歷史，讓重新啟動後仍能延續脈絡。記憶存於該使用者的本機資料夾，不等於自動雲端同步。

02 / INDEPENDENT JUDGMENT

訓練實驗

Kaptia 不應只附和使用者：要能比較選項、指出矛盾、提出反例，並依新證據修正判斷。這是助理行為設計，不代表它具有意識。

03 / PERSONALITY

每台電腦的個人化

本機歷史讓助手能延續近期談話；更長期的偏好整理、可編輯記憶與跨話題回憶仍需逐步實作與驗收，不能把尚未完成的能力當成現有功能。

GET STARTED

從第一次對話開始建立自己的助手

STEP 01
下載並確認版本

直接在本網站查看版本說明並下載安裝檔。請確認該版本是否已包含本機記憶功能，不要把官網改版當成安裝器已更新。

STEP 02
開始自然對話

像一般助手一樣提出問題、修正回答，並逐步建立可延續的對話脈絡。

STEP 03
檢查與管理記憶

本機記憶應能查閱與清除。新版記憶功能完成發布前，請以目前安裝器實際提供的命令與功能為準。

PRIVACY & CONTROL

記憶屬於你，控制權也應屬於你

作業系統

Windows 10 或 Windows 11（64 位元）。目前此安裝流程不是 iPhone/iPad 安裝程式。

本機資料位置

對話記憶應存放於目前 Windows 使用者的本機資料夾，讓不同電腦各自保有獨立記憶；本機檔案不會因網站發布而自動同步。

記憶控制

設計方向包含查看記憶狀態、清除本機歷史與限制儲存量。只有已經整合並發布的版本才可視為可用。

外部服務與隱私

本機記憶模組本身不需要把聊天上傳到雲端。若選擇外接 API，對話內容可能送往服務商；請先檢查設定與隱私條款。
